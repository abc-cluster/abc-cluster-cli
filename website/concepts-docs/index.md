# Concepts — coming soon

This space is reserved for **platform-wide concepts** shared across every
abc-cluster project (the `docs-common` set): the ideas, terminology, and
models that aren't specific to the CLI but underpin the whole platform —
data sovereignty regions, tiers, jobs vs pipelines vs modules, accounting
and showback, and how the pieces fit together.

For now, project-specific documentation lives under each project. Start
with the [CLI docs](/docs/cli). Concept pages will be published here as the
shared `docs-common` content is inventoried and promoted.
